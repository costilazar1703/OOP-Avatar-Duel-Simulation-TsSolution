# OOP Avatar Duel Simulation ⚔️

A command-line simulation of a turn-based duel between customizable avatars. This project was developed to strongly demonstrate the core principles of Object-Oriented Programming (OOP) in C++.

## 🚀 Key Features
* **Custom Avatar Classes:** Distinct character types with unique attributes (health, attack power, defense).
* **Combat System:** A turn-based simulation engine calculating damage based on stats, critical hits, and defensive mitigation.
* **Dynamic Instantiation:** Object lifecycle management and memory handling for combatants.

## 🧠 Core OOP Concepts Demonstrated
* **Encapsulation:** Protecting internal avatar states and modifying them strictly through dedicated methods.
* **Inheritance:** Base class architecture extended by specific avatar subclasses.
* **Polymorphism:** Method overriding for specialized attack or defense behaviors depending on the avatar type.

## 🛠️ Tech Stack
* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)

## 💻 Getting Started
1. Clone this repository.
2. Compile the source code using any standard C++ compiler (e.g., `g++ main.cpp -o duel`).
3. Run the executable to watch the simulation unfold in the terminal.
